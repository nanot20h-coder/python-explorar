# Gestor de inventario Novexa — Laboratorio 3

Este programa de consola organiza recursos digitales de una empresa: logotipos,
plantillas, paletas de color, manuales de marca y otros activos creativos.

## Requisitos
- Python 3.10 o posterior.
- No requiere instalar paquetes externos.

## Ejecución
Desde esta carpeta, ejecuta: gestor_inventario

```bash
python main.py
```

Los datos se mantienen en memoria mientras se ejecuta el programa. La persistencia
en archivos JSON y la exportación a CSV se incorporan en la versión del Laboratorio 4.
