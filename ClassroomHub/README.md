# ClassroomHub

## Descripción

ClassroomHub es un sitio web desarrollado con Django como parte de un laboratorio de aprendizaje. Su objetivo es practicar la creación de rutas, vistas y plantillas.

## Funcionalidades

- Página principal con mensaje de bienvenida.
- Página para consultar recursos educativos.
- Página con información sobre el proyecto.
- Navegación entre las diferentes páginas.
- Visualización de la disponibilidad de los recursos.
- Respuesta 404 para páginas que no existen.

## Tecnologías utilizadas

- Python
- Django
- HTML
- SQLite

## Ejecutar el proyecto

1. Clonar o descargar el repositorio.
2. Crear y activar el entorno virtual.
3. Instalar las dependencias:

   `pip install -r requirements.txt`

4. Ejecutar el servidor:

   `python manage.py runserver`

5. Abrir en el navegador:

   `http://127.0.0.1:8000/`

## Estructura

- `config/`: configuración del proyecto.
- `pages/`: aplicación principal.
- `templates/`: plantillas HTML.
- `manage.py`: archivo para ejecutar comandos de Django.
