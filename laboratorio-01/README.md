# Laboratorio 01 - Fundamentos de Python

## Descripción

En este laboratorio trabajé los conceptos básicos de Python mediante diferentes ejercicios prácticos. También desarrollé un cotizador de compra para aplicar lo aprendido.

## Objetivos

- Practicar el uso de variables y tipos de datos.
- Realizar operaciones matemáticas.
- Recibir y validar información ingresada por el usuario.
- Desarrollar programas sencillos en Python.

## Archivos y actividades

- `cotizador_compra.py`: solicita los datos de una compra y calcula el subtotal, el descuento, el impuesto y el total a pagar.
- Otros archivos `.py`: contienen los ejercicios realizados durante el laboratorio.

## Requisitos

- Python 3.
- Visual Studio Code o un editor de código similar.

## Cómo ejecutar los programas

Abre una terminal en esta carpeta y ejecuta el archivo que quieras probar. Por ejemplo:

```bash
py cotizador_compra.py
```

## Pruebas realizadas

Se realizaron pruebas con diferentes precios, cantidades, descuentos e impuestos. También se probaron entradas incorrectas para comprobar que el programa mostrara mensajes de error y solicitara nuevamente los datos.

## Aprendizajes

Aprendí a utilizar variables, operaciones matemáticas, conversiones de datos y validaciones para mejorar el funcionamiento de los programas.
